"A living archive of a human life."

User sedang menjelajahi dirinya sendiri.

# Border Radius

Small

8px

Cards

16px

Modal

20px

Character Panels

24px

Avoid overly rounded "AI SaaS" style.

---

# Shadows

Never use heavy shadows.

Use subtle depth:

0px 4px 24px rgba(0,0,0,0.25)

Soft and atmospheric.

---

# Motion Guidelines

Animation Style:
Slow
Intentional
Organic

Avoid:

- Bounce
- Overshoot
- Cartoon effects

Preferred:

- Fade
- Slide
- Parallax
- Smooth reveal

---

# Timeline Design

Visual Inspiration:

Git Commit History

- Personal Memory Album

Each memory represented as:

● Memory Node

Connected through timeline paths.

Important milestones appear larger.

---

# Commit Card Style

Example:

commit 81fd2e

May 30, 2026

Mood:
Hopeful

XP:

---

# Character System

The character is not an avatar.

The character is:

"A visual representation of the user's current state."

Changes:

- Environment
- Aura
- Room
- Weather
- Lighting

Based on:

- Mood
- Journal Activity
- Achievements
- Life Commits

---

# Empty State Design

Never show:

"No Data Found"

Instead show:

"This chapter hasn't been written yet."

or

"No memories recorded for this period."

---

# Achievement Design

Not gamified.

More like life milestones.

Examples:

First Step

Completed your first life commit.

---

New Chapter

Added 50 memories.

---

Still Growing

Maintained a 30-day reflection streak.

---

# Sound Design (Future)

Soft:

- keyboard sounds
- paper sounds
- ambient room sounds
- rain ambience
- subtle UI clicks

No arcade sounds.

No reward explosions.

Version of Me
