# PRODUCT REQUIREMENT DOCUMENT (PRD)

## Project Name

Version of Me _(working title)_

---

# 1. Product Overview

Version of Me adalah sebuah web application berbasis personal digital archive yang memungkinkan pengguna mendokumentasikan perjalanan hidup mereka dalam bentuk timeline interaktif yang hidup dan terus berkembang.

Aplikasi ini menggabungkan elemen:

- journaling,
- self-growth tracking,
- emotional logging,
- achievement system,
- relationship mapping,
- dan visual storytelling.

Konsep utama aplikasi adalah:

> “Hidup manusia direpresentasikan seperti evolving software project.”

Pengguna dapat membuat “life commits”, mencatat perubahan diri, membangun karakter digital, serta melihat perkembangan hidup mereka melalui visual timeline dan sistem pertumbuhan karakter.

---

# 2. Problem Statement

Sebagian besar aplikasi journaling atau productivity saat ini terasa terlalu formal, monoton, dan tidak memiliki emotional connection terhadap penggunanya.

Pengguna sering kesulitan:

- memahami perkembangan diri mereka,
- mendokumentasikan perjalanan hidup secara meaningful,
- mempertahankan motivasi self-improvement,
- dan mengekspresikan emosi secara personal.

Dibutuhkan sebuah platform yang:

- lebih personal,
- lebih emosional,
- dan terasa hidup.

---

# 5. Core Features

## 5.1 Life Timeline

Pengguna dapat melihat perjalanan hidup mereka dalam bentuk timeline interaktif.

### Features:

- Add memory
- Add milestone
- Add photo/music/mood
- Categorize events
- Timeline filtering

---

## 5.2 Emotional Commit System

Pengguna dapat membuat “life commits” seperti git commit.

### Examples:

- “learned to let go”
- “removed toxic dependency”
- “started healing”

### Features:

- Commit title
- Emotional tags
- Commit history
- Commit streak
- Commit mood

---

## 5.3 Character Growth System

Pengguna memiliki representasi karakter digital yang berkembang seiring aktivitas pengguna.

### Character Attributes:

- Confidence
- Discipline
- Happiness
- Creativity
- Social Energy
- Emotional Stability

### Features:

- Level system
- XP system
- Dynamic environment
- Mood-based appearance

---

## 5.4 Relationship System

Pengguna dapat mencatat hubungan sosial mereka.

### Features:

- Add person
- Relationship status
- Relationship timeline
- Shared memories
- Emotional impact tracking

### Status Examples:

- Active
- Faded
- Archived
- Lost Connection

---

## 5.5 Achievement System

Pengguna dapat memperoleh achievement berdasarkan progress hidup mereka.

### Examples:

- “30 Days Consistency”
- “First Recovery Arc”
- “New Beginning”
- “Social Comeback”

---

## 5.6 Journal & Reflection

Pengguna dapat menulis refleksi pribadi secara bebas.

### Features:

- Daily journal
- Mood logging
- Reflection prompts
- Private entries
